# Tirage BrandQuest

Le site : https://thorn96.github.io/Cartes-Lucas/

Tuto complet, de la création du compte GitHub à l'ajout de cartes : https://thorn96.github.io/Cartes-Lucas/tuto.html

## Ajouter une carte

1. Sur le site, clique sur **Ajouter un bonus** ou **Ajouter un malus** (ou ouvre [`cartes/bonus`](cartes/bonus) ou [`cartes/malus`](cartes/malus) ici et clique sur **Add file → Upload files**).
2. Glisse l'image du recto (PNG, JPEG, WebP ou GIF).
3. Clique sur **Commit changes**.

La carte apparaît sur le site au prochain rechargement (compte une minute).

Le type (bonus ou malus) vient du dossier. Sinon, il vient du nom du fichier s'il contient « bonus » ou « malus » (le dossier l'emporte en cas de désaccord).

## Retirer une carte

Ouvre l'image dans [`cartes/bonus`](cartes/bonus) ou [`cartes/malus`](cartes/malus), clique sur **⋯ → Delete file**, puis **Commit changes**.

Le dos des cartes est `verso.webp`.
