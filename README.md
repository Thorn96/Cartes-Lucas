# Tirage BrandQuest

Le site : https://thorn96.github.io/Cartes-Lucas/

## Ajouter une carte

1. Sur le site, clique sur **Ajouter des cartes** (ou ouvre le dossier [`cartes`](cartes) ici et clique sur **Add file → Upload files**).
2. Glisse l'image du recto (PNG, JPEG, WebP ou GIF).
3. Clique sur **Commit changes**.

La carte apparaît sur le site au prochain rechargement (compte une minute).

## Retirer une carte

Ouvre l'image dans le dossier [`cartes`](cartes), clique sur **⋯ → Delete file**, puis **Commit changes**.

Le dos des cartes est `verso.webp`.
