Ajouter tes propres cartes

Les cartes du tirage sont des images rangées sur GitHub, dans le dossier cartes/bonus ou cartes/malus selon leur type. Une fois ton compte créé et l’invitation acceptée (à faire une seule fois), ajouter une carte prend 30 secondes.

Une seule fois : ton accès

  1. Crée ton compte GitHub (gratuit)

    • Va sur github.com/signup.
    • Entre ton adresse e-mail, choisis un mot de passe et un nom d’utilisateur, puis valide la petite vérification anti-robot.
    • GitHub t’envoie un code par e-mail : recopie-le pour activer le compte.
    • S’il te pose des questions sur ton usage ou te propose une offre payante, passe : le compte gratuit suffit.

  2. Envoie ton nom d’utilisateur à Leonard

    C’est le nom choisi à l’étape 1 (pas ton e-mail). Leonard t’ajoute alors au projet Cartes-Lucas.

  3. Accepte l’invitation

    • Tu reçois un e-mail de GitHub : « Thorn96 invited you to collaborate ».
    • Clique sur View invitation, puis sur Accept invitation.
    • Pas d’e-mail ? Ouvre directement github.com/Thorn96/Cartes-Lucas/invitations en étant connecté.

    L’invitation expire au bout de 7 jours. Passé ce délai, demande à Leonard de la renvoyer.

  4. Mets le tirage en favori

    thorn96.github.io/Cartes-Lucas : c’est la page du tirage et elle ne change jamais d’adresse.

À chaque nouvelle carte

  1. Prépare l’image

    • Le recto de la carte, en PNG, JPEG, WebP ou GIF, moins de 25 Mo.
    • Au même format que les autres cartes, en hauteur (environ 827 × 1417 pixels), sinon elle sera recadrée.
    • Le nom du fichier devient le nom de la carte : par exemple Malus - Budget gelé.png.

    Pas besoin de faire le dos : il est commun à toutes les cartes.

  2. Ouvre la page d’ajout

    En bas de la page du tirage, clique sur Ajouter un bonus ou Ajouter un malus selon la carte. La page GitHub d’envoi s’ouvre directement dans le bon dossier.

    C’est le dossier qui dit si une carte est un bonus ou un malus. Une image mise directement dans cartes est tirée aussi, mais comptée « sans type ».

    Si GitHub te demande de te connecter, fais-le avec ton compte.

  3. Glisse tes images

    Dépose une ou plusieurs images dans le grand cadre, ou clique sur choose your files pour les choisir.

  4. Valide

    En bas de la page, laisse l’option Commit directly to the main branch cochée et clique sur le bouton vert Commit changes.

  5. Recharge le tirage

    Attends environ une minute, puis recharge la page du tirage : ta carte apparaît avec les autres et entre dans le prochain tirage.

Tirer seulement certaines cartes (les decks)

  1. Crée un deck

    Sur la page du tirage, clique sur Gérer les decks (au-dessus des cartes), puis sur + Nouveau deck. Donne-lui un nom, par exemple « Session du lundi ».

  2. Coche ses cartes

    Les cartes sont rangées en Bonus et Malus. Coche celles du deck : le compteur affiche par exemple « 5 / 20 cartes · 3 bonus · 2 malus ». Tout cocher et Tout décocher font gagner du temps.

    Tu peux créer autant de decks que tu veux. Chaque changement est enregistré tout de suite.

  3. Tire avec ce deck

    Clique sur Tirer avec ce deck, ou choisis le deck dans la liste au-dessus de la table du tirage. Seules ses cartes sont mélangées, et chacune a la même chance de sortir. Il faut au moins 2 cartes dans le deck.

    Les decks sont enregistrés dans ton navigateur, sur cet appareil : ils sont toujours là quand tu reviens, mais pas sur tes autres appareils. Une carte ajoutée plus tard n’entre dans un deck que si tu la coches.

Retirer, renommer ou changer le type d’une carte

  1. Ouvre le dossier des cartes

    github.com/Thorn96/Cartes-Lucas/tree/main/cartes, ouvre le dossier bonus ou malus, puis clique sur l’image à retirer.

  2. Supprime-la

    Clique sur le menu ⋯ en haut à droite de l’image, puis Delete file, puis Commit changes.

    Pour renommer une carte ou la passer de bonus à malus : supprime-la, puis renvoie l’image avec le bon nom, dans le bon dossier.

Si ça coince

La page d’ajout affiche « 404 » ou pas de bouton pour envoyer.
Tu n’es pas connecté à GitHub, ou l’invitation n’est pas encore acceptée (étape 3).
Ma carte n’apparaît pas.
Attends une ou deux minutes, puis recharge avec Ctrl + F5. Vérifie aussi que le fichier est bien dans cartes/bonus ou cartes/malus.
Le tirage affiche « Impossible de charger les cartes ».
GitHub limite à 60 chargements par heure et par connexion internet. Réessaie un peu plus tard.
Le bouton « Lancer le tirage » est grisé.
Il faut au moins deux cartes dans le deck.
